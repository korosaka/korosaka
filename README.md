# Koro Saka / モバイルアプリエンジニア

iOS・Android(ネイティブ)・Flutter の3つすべてで実務経験のあるモバイルアプリエンジニアです。
カナダ・バンクーバーの企業での開発経験と英語力を活かし、海外チームとのやり取りにも対応できます。

## 強み

- **iOS / Android / Flutter すべてに対応**
  ネイティブとクロスプラットフォームの両方を経験しているため、案件に合った技術選定や既存アプリの改修にも柔軟に対応できます。
- **不具合修正による品質改善**
  既存アプリの不具合の調査・修正を数多く担当してきました。原因を突き止めて品質を安定させる作業が得意です。
- **個人アプリを8年以上運営(累計4万DL以上・評価★4.3)**
  企画・設計・開発・リリース・運営・収益化(アプリ内課金・広告)まで、一人で一通り経験しています。
- **海外での開発経験と英語力**
  バンクーバーの受託開発企業(Ensemble Systems)とスタートアップ(Life Lapse)で勤務し、世界的なニュースアプリの開発に携わりました。英語のドキュメントやコミュニケーションにも抵抗はありません。
- **AI を活用した開発**
  Claude Code を日常的に開発へ取り入れ、実装・調査のスピードを上げています。

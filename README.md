### ⛳ ゴルフ場ナビシステム
**業務委託 / 2024年11月〜現在 / チーム3名(開発2名)・全体8名 / Android・iOS**

`Flutter` `Dart` `Kotlin` `GetX` `Amazon Chime SDK` `Bluetooth` `Firebase Crashlytics` `Claude Code`

- ゴルフ場のカートで使うタブレット/スマホ向けアプリの開発に参画。iPad版(Swift)の既存機能を Flutter へ移植し、主に Android 端末での動作を担当
- 参画時はクラッシュが多い状態だったが、Firebase Crashlytics で原因を一つずつ特定・修正して安定化に貢献(タスクの約半分が不具合修正)。**契約を更新し、2年以上継続中**
- 通話(Amazon Chime SDK)や Bluetooth など、ハードウェアに関わる部分で Flutter とネイティブ(Kotlin)の連携を多数実装
- 自分からタスク管理表を作成し、バックエンドを含む他ベンダーと API 仕様の確認や提案で連携
